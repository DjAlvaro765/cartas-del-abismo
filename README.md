# Cartas del Abismo
Roguelike de cartas hecho con Python y Pygame. Sube 10 pisos, arma tu mazo y derrota al Dragón del Abismo.

## Cómo jugar
1. Instala Python desde python.org
2. Instala la librería: python -m pip install pygame-ce
3. Ejecuta: python cartas_del_abismo.py

## Controles
- Clic en una carta (o teclas 1-9): jugarla
- Clic en un enemigo: elegirlo como objetivo
- ESPACIO: terminar el turno
